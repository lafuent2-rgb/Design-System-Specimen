Design System

Interface Specimen

A small design system showing foundational styles, tokens, typography, actions, surfaces, and form controls.

Viewport status: wide

S1 — Foundation and Reset

This project uses a small selective reset instead of removing every browser default.

  • box-sizing: border-box keeps declared widths easier to calculate because padding and borders are included in the element width.
  • body { margin: 0; } removes the browser's default body margin so page spacing can be controlled intentionally.
  • Images and SVGs use max-width: 100% so they do not overflow their containers.
  • Heading, paragraph, list, and form defaults are not completely removed because useful browser behavior is intentionally preserved.

S2 — Token Inventory

These tokens provide reusable values for color, spacing, typography, and border radius throughout the design system.

Color Tokens

--color-primary
--color-text
--color-surface

Semantic Tokens

--color-action, --color-action-hover, --color-page, --color-card, --color-copy, --color-copy-muted

Usage Note

Semantic tokens should be used when styling interface roles such as actions, page backgrounds, surfaces, and text. This keeps component styles consistent even if the underlying color values change later.

S4 — Actions and States

Action styles provide clear interactive controls with visible hover, focus, and disabled states.

Usage Note

Primary actions are used for the most important action in a section. Secondary actions are used for less prominent choices. Interactive controls should provide visible hover and keyboard focus states, while unavailable actions should use the disabled state.

S5 — Surfaces and Content Patterns

Surface patterns group related information into clear and reusable content areas.

Usage Note

Cards should group related content that belongs together. Use consistent spacing, borders, radius, and surface colors across cards. Avoid using cards when the content does not need to be visually separated.

S6 — Control Foundations

Form controls use consistent labels, spacing, borders, and focus states to make user input clear and accessible.

Usage Note

Form controls should use clear labels, consistent spacing, and visible keyboard focus states. These examples establish basic control styling; full form design is reserved for Module 3.
